**Module doc comment:**
```rust
//! Image format conversion module
//!
//! Provides byte-in, byte-out image format conversion. Decodes source image
//! bytes using the `image` crate and re-encodes to a target format (JPEG, PNG,
//! or WebP). Handles alpha compositing for JPEG conversion and provides lossy
//! WebP encoding via the `webp` crate.
//!
//! Note: Animated GIFs are decoded as their first frame only.
```

**Public API (per D-04, D-05, D-06):**

1. `OutputFormat` enum (per D-05):
```rust
#[derive(Debug, Clone, Copy, PartialEq, Eq)]
pub enum OutputFormat {
    Jpg,
    Png,
    Webp,
}
```

2. `can_convert(extension: &str) -> bool` (per D-06, D-13):
   Returns true for: "jpg", "jpeg", "png", "gif", "bmp", "tiff", "tif", "webp", "ico" (case-insensitive via `.to_lowercase()`).
   Returns false for everything else including "svg", "wmf", "emf".
   Use `matches!()` macro on the lowercased string.

3. `convert_image(data: &[u8], format: OutputFormat, quality: u8) -> Result<Option<Vec<u8>>>` (per D-04):
   Three-stage pipeline:
   
   **Stage 1 - Decode:**
   Call `image::load_from_memory(data)`. On error, match the error variant:
   - `ImageError::Unsupported(_)` => return `Ok(None)` (per D-11)
   - Any other `ImageError` variant => return `Err(e).context("Failed to decode image")` (per D-12)
   
   **Stage 2 - Alpha compositing (JPEG only, per D-08, D-09, D-10):**
   If `format == OutputFormat::Jpg` AND `img.color().has_alpha()`, call `composite_on_white(&img)` to get an RGB image.
   Otherwise, use the decoded image as-is.
   For PNG and WebP targets, do NOT composite -- preserve alpha (per D-09).
   
   **Stage 3 - Encode:**
   Match on `format`:
   - `OutputFormat::Jpg` => call `encode_jpeg(&img, quality)` using `JpegEncoder::new_with_quality(&mut buf, quality)` then `img.write_with_encoder(encoder)`. CRITICAL: Do NOT use `JpegEncoder::new()` (defaults to quality 75, violates CONV-05/D-14). Do NOT use `img.write_to(&mut buf, ImageFormat::Jpeg)` (also defaults to 75).
   - `OutputFormat::Png` => call `encode_png(&img)` using `PngEncoder::new(&mut buf)` then `img.write_with_encoder(encoder)`. Quality parameter is ignored for PNG (lossless).
   - `OutputFormat::Webp` => call `encode_webp_lossy(&img, quality)` using `webp::Encoder::from_image(&img).map_err(|e| anyhow::anyhow!("WebP encoder creation failed: {}", e))?` then `encoder.encode(quality as f32)` which returns `WebPMemory`. Call `.to_vec()` to get `Vec<u8>`. Per D-01, D-15, this is lossy encoding with default quality 85.
   
   Return `Ok(Some(encoded_bytes))`.

**Private helper functions:**

4. `composite_on_white(img: &DynamicImage) -> DynamicImage`:
   - Call `img.to_rgba8()` to get `RgbaImage`
   - Create `RgbImage::new(width, height)`
   - For each pixel, apply alpha compositing formula:
     ```
     alpha = a as f32 / 255.0
     inv_alpha = 1.0 - alpha
     out_r = (r as f32 * alpha + 255.0 * inv_alpha) as u8
     out_g = (g as f32 * alpha + 255.0 * inv_alpha) as u8
     out_b = (b as f32 * alpha + 255.0 * inv_alpha) as u8
     ```
   - Return `DynamicImage::ImageRgb8(rgb)`

5. `encode_jpeg(img: &DynamicImage, quality: u8) -> Result<Vec<u8>>`:
   - `let mut buf = Vec::new();`
   - `let encoder = image::codecs::jpeg::JpegEncoder::new_with_quality(&mut buf, quality);`
   - `img.write_with_encoder(encoder).context("Failed to encode JPEG")?;`
   - Return `Ok(buf)`

6. `encode_png(img: &DynamicImage) -> Result<Vec<u8>>`:
   - `let mut buf = Vec::new();`
   - `let encoder = image::codecs::png::PngEncoder::new(&mut buf);`
   - `img.write_with_encoder(encoder).context("Failed to encode PNG")?;`
   - Return `Ok(buf)`

7. `encode_webp_lossy(img: &DynamicImage, quality: u8) -> Result<Vec<u8>>`:
   - `let encoder = webp::Encoder::from_image(img).map_err(|e| anyhow::anyhow!("WebP encoder creation failed: {}", e))?;`
   - `let webp_data = encoder.encode(quality as f32);`
   - Return `Ok(webp_data.to_vec())`
